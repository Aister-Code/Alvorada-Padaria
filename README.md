# ERP Alvorada Padaria

ERP operacional para a Alvorada Padaria, Lanchonete e Pizzaria.

## Objetivo

Centralizar os fluxos principais da operação: atendimento, pedidos, delivery, caixa, usuários e base administrativa.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Convex
- shadcn/ui

## Instalação

```bash
npm install
```

## Execução

```bash
npx convex dev
npm run dev
```

## Estrutura

- `convex/`: backend, schema e funções Convex.
- `src/`: frontend React.
- `src/pages/`: telas do ERP.
- `src/components/`: providers e componentes UI.
- `src/hooks/`: hooks compartilhados.
- `src/lib/`: utilitários.
- `docs/`: documentação técnica.
